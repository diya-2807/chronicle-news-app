# The Chronicle — Global Dispatch & Perspectives

An editorial news dashboard and article reader application built with pure HTML, CSS, and vanilla JavaScript.

## Features
- **Zero API Key Required**: Pre-loaded catalog of realistic news articles covering General, Technology, Business, Science, Health, and Sports.
- **Editorial Typography**: Elegant layout with `Newsreader` and `Plus Jakarta Sans`.
- **Instant Search**: Real-time headline filtering.
- **Reading List Bookmarks**: Save articles to `localStorage`.
- **Full Article Modal**: Modal reader with key takeaway highlights.

## Running Locally
Open `index.html` in any browser. No build steps or API keys required.
